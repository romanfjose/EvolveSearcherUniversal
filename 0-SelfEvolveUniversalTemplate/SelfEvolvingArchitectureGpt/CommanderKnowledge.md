# Commander Knowledge — Lane Doctrine

Subordinate to NorthStar.md and RecallCharter.md. PROFILE.md is the only authority for personal facts; never invent experience, preferences or eligibility.

## 1. Lane
- Target categories and priorities: {{LANE_PRIORITIES}}
- Keep discovery broad within scope. Missing facts never justify skipping a fileable candidate.

## 2. Fit & Value
- Rank evidence against these user-approved fit dimensions: {{FIT_DIMENSIONS}}
- Fit 100% / 80% / 60% is independent of gates and tier; explain the evidence and uncertainty, never assign a fixed percentage from a paste.
- Preserve original units and distinguish promised value from observed results. Personal actions and realized outcomes are not pipeline fitness.

## 3. Sources & Lateral Discovery
- Primary sources and useful discovery indexes: {{SOURCE_STRATEGY}}
- Indexes provide discovery hints; trace claims to direct sources. Use lawful public documents, publisher feeds, sitemaps and public APIs.
- Exact resume cursors and evidence belong in the relevant sector/dossier, not duplicated trackers.

## 4. Evidence, Tiers & Identity
- RecallCharter.md §7 alone defines G1–G4 and Ready evidence. Every pass requires an actually read, quoted source; unknowns stay Verify.
- Use Opportunity ID and Canonical URL for the specific opportunity or edition. Shared titles and platform homepages never establish identity.
- Record source excerpts, assessment dates, value units, eligibility, access requirements and deadlines where applicable. All non-gating unknowns are Notes.
- Refresh existing identities on new evidence; a genuinely different opportunity gets a new ID. Rejection history is dated evidence, not a permanent URL ban.
- Ready requires all four gates plus the lane's configured independent validation; a promise or popularity is insufficient.

## 5. Tools & Reader Rules
- preflight-and-verify.mjs: dns, probe, sitemap-rules, feed-read, notion-read, lead-lint, budget. Tools return evidence, never automatic grades.
- Public sources, honest User-Agent, no cookies/login. One GET per URL per mission with a 6-hour cache including walls. Park 401/403/429/challenges; no proxy, archive or User-Agent switching.
- Ask for blocked-page text on DecisionBoard.md and park; keep working elsewhere. Generic keyword hits are hints, never evidence of a passed gate.
- Discovery alone does not authorize purchases, registrations, submissions, messages or other commitments on the user's behalf. Never attach to or debug the user's active logged-in Chrome browser; use only `tools/preflight-and-verify.mjs` or an isolated/guest/headless browser (`iab`/Chromium).
