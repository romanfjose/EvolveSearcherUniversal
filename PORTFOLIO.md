# Engineering Portfolio

Ten packages in one monorepo, grouped by the problem they solve. **[▶ Interactive hub](docs/portfolio/index.html)** has filters, architecture diagrams, live demo previews and a "when to hire me" brief for each one. Serve the repo root (`python3 -m http.server`) and open `/docs/portfolio/`.

## Verification
